# 1. Алдагдсан дамжуулалт

Танд дугаартай баримт (v36) байна.

- A хэсэг: нууцалсан зурвас (`packet.md`).
- B хэсэг: HTTP статус кодын хүснэгт (`http-status.md`).
- C хэсэг: цагаан толгойн мөр (`packet.md`).
- D хэсэг: нуусан захидал (`envelope.md`).

Зурвасыг тайлбал сүүлийн мөрөнд алдагдсан захидлын шошго гарна. Тэр шошготой захидлыг `envelope.md`-ээс унш.

Шалгах хуудсанд (`check.html`) оруулах:
1. Тайлсан зурвас: эхний мөрийн өгүүлбэр.
2. Захидлын шошго: сүүлийн мөрийн 3 үсэг.
3. Захидлын код: 4 оронтой тоо.

Талбаруудыг тус тусад нь илгээж болно. Латин үсгээр бич. Зай, том жижиг үсэг хамаагүй.
