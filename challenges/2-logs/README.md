# 2. Холбоосыг хэн эвдэв?

Их сургуулийн сайтаас нэг зарлал гэнэт алга болж 404 алдаа харуулах болжээ. Хэн нэгэн админ самбараас устгасан байх гэж таамаглав.

Файлууд (зохиомол өгөгдөл: IP, хэрэглэгч, үйл явдал бүгд зохиомол):
- `access.log`: num.edu.mn-ийн веб серверүүдийн нэг өдрийн хандалтын лог. Мөр бүр хостын нэрээр эхэлнэ.
- `auth.log`: сайтын админ самбар болон нэгдсэн нэвтрэлтийн (SSO) лог.

Бүх цаг +08:00 (Улаанбаатар).

Олох зүйл:
1. Зарлалын дугаар: алга болсон зарлалын хаяг `/announcement/<дугаар>`-ын дугаар.
2. Хэрэглэгчийн нэр: зарлалыг устгасан админ.
3. IP хаяг: устгах хүсэлт ирсэн хаяг.
4. Цаг: устгах хүсэлт ирсэн цаг, минутаар (ЦЦ:ММ). Секундийг тоймлохгүй, хаяна: 15:04:45 бол `15:04`.

Талбаруудыг тус тусад нь илгээж болно. Хариуг латин үсгээр бич.

Лог файл том бөгөөд ямар хэрэгсэл ашиглахаа өөрсдөө шийдээрэй.
