# 4. Эвдэрсэн портал

Оюутны порталд алдаанууд нуугдсан. Буруу ажиллаж буй зүйлийг олоод, тэр элемент дээрээс нь мэдээл.

Веб хувилбар: https://bilguun0203.github.io/ortoo2026-challenges/glitch/

Эсвэл өөрийн компьютер дээр ажиллуул (Node хэрэгтэй):

```
cd portal
npm ci
npm run dev
```

Мэдээлэх:
1. «Алдаа мэдээлэх» горимыг асаа.
2. Буруу үр дүн гарч буй элементийг дар.
3. Алдааны ангиллыг сонгоод илгээ.

- Алдаа хүндрэлээсээ хамаарч (хөнгөн, дунд, хүнд) өөр оноотой.
- Нэг алдааг нэг л удаа тоолно.
- Явц хөтөч дээр хадгалагдана.
